公众号草稿推送 · 服务器版
================================

前提：Python 3（脚本纯标准库，不用装任何东西）
前提：本服务器公网 IP 已加入公众号「设置与开发 → 基本配置 → IP白名单」

一、跑起来
----------
    export WECHAT_SECRET="AppSecret"
    chmod +x run.sh && ./run.sh

AppSecret 只走环境变量，不写进任何文件。

二、脚本做什么
--------------
  第一步 dry-run   7 张图片上传微信图床，换掉本地路径，不建草稿
  第二步 你按 y    才正式建草稿（带封面）

三、报错对照
------------
  40164 invalid ip          服务器 IP 没加白名单（最常见）
  40001 invalid credential   AppSecret 不对，重新 export 一次
  45009 api freq limit      调太频繁，等一会
  标题被截断                 ≤64 字节（约 21 个汉字）
  摘要被截断                 ≤120 字
