# 教学演示 · 实时 3D 设计稿

> **目标**：一个几百 KB 的 HTML，双击打开就是一个能走进去的课堂场景。学生的第一反应应该是「这不可能」，第二反应是「老师再放一遍」。
> **原则**（取自参考文章）：程序化生成、单文件不引外部素材、组件解耦、光照雾气色调、普通笔记本流畅、改完截图自审。
> **注意**：这是设计稿，不是成品。确认方向后我再写代码，先出「开场 3 秒」验证观感。

---

## 一、选题：为什么是赵州桥

| 理由 | 说明 |
|---|---|
| 有课文 | 小学语文《赵州桥》原文就在讲「雄伟、坚固、美观」，三个词正好对应桥的三种可视化 |
| 有跨学科接口 | 拱形受力（物理）、隋朝李春（历史）、石雕纹样（美术），一个场景能串四门课 |
| 对标文章例子 | 文章里的洪崖洞是「建筑 + 江水 + 灯火 + 雾气」，赵州桥是同一套视觉语言，但教学价值更高 |
| 已有素材基础 | 蓝皮书第 15 专题做过 9 页《赵州桥》希沃课件，这个 3D 场景可以直接当它的「导入页」 |

**一句话卖点**：课件里那张赵州桥插图是死的，这个是活的——能转、能走、能拆开看拱。

## 三、场景拆解（全部代码生成，0 张图片）

## 四、开场 20 秒镜头脚本（这一段决定「不可能」）

| 时间 | 画面 | 音效建议 |
|---|---|---|
| 0.0–0.8s | 全黑，只有一行小字「赵州桥 · 隋 · 李春」 | 一声水滴 |
| 0.8–3.5s | 石块从水下浮起，逐块拼成大拱（先拱圈，后桥面） | 低频轰鸣 + 石头落位声 |
| 3.5–6s | 镜头贴水面推进，穿过桥洞，看到月亮在桥洞那头 | 水声渐强 |
| 6–10s | 环绕拉升，四个小拱依次被暖灯点亮 | 灯光逐个「啵」 |
| 10–14s | 栏板浮雕特写，龙纹在光里浮出来 | 轻微弦乐 |
| 14–20s | 拉到全景，雾起，萤火虫出现，落标题 | 音乐收尾 |

**关键**：前 3 秒不放任何文字说明，只让石块自己拼起来。人看到「东西从无到有造出来」，才会觉得不可能。

## 五、「不可能感」的三个钩子

1. **体积反差**：打开前告诉他们「这个文件 380KB」，打开后再看画面。反差本身就是内容。
2. **建桥动画**：石块拼合那 3 秒，是全场唯一必须重播的片段。
3. **拆桥模式**：一键把桥拆成拱圈、桥面、栏板三层悬浮展开，标出受力线——这是课件做不到的事。

## 六、交互与三种教学模式

| 模式 | 画面 | 教学用途 |
|---|---|---|
| **夜景写实**（默认） | 月光、灯火、水面、雾 | 导入：先让学生「看见」这座桥 |
| **结构透视** | 桥体半透明，拱圈高亮，压力线沿拱传递 | 讲「坚固」：为什么拱形能承重 |
| **雕刻细节** | 镜头贴近栏板，纹样放大，标注「龙纹/云纹」 | 讲「美观」：课文里的「精美的图案」 |

- 操作：拖拽旋转、滚轮缩放、双击回到默认机位。
- 三个热点：大拱（跨 37 米）、小拱（泄洪）、栏板（42 块）。
- 一个按钮：「重播建桥」。

## 七、技术结构（模块解耦，方便你后面单独改）

```
教学3D演示/
├── index.html          单文件入口（构建时内联所有模块）
├── src/
│   ├── core.js         渲染器、相机、循环、自适应分辨率
│   ├── bridge.js       参数化桥体（跨度/拱高/小拱数）
│   ├── rail.js         栏板与浮雕 shader
│   ├── water.js        水面与倒影层
│   ├── sky.js          星空、月亮、雾
│   ├── lights.js       月光 + 桥洞暖光 + 萤火虫
│   ├── camera.js       开场镜头脚本 + 自由漫游
│   └── ui.js           模式切换、热点、字幕
└── build.py            把 src 内联成单个 index.html
```

**为什么这么拆**：文章里那条「主要物体都做成独立组件」是硬要求。桥想改高一点、灯想换颜色，都只动一个文件。

## 十、风险与降级方案

| 风险 | 降级 |
|---|---|
| Three.js 内联后体积超标 | 改用极简自写 WebGL 渲染器，只保留要用的功能，可压到 60KB |
| 水面反射太吃性能 | 去掉真反射，只留倒影层 + 波纹法线 |
| 栏板浮雕 shader 写不出细节 | 退化为几何浮雕（挤出 2mm）+ 简单噪声，面数 +3k |
| 集显掉帧 | 自动降分辨率 + 雾距缩短，保证 45fps |
| 建桥动画石块穿插 | 预计算每块石的起止位置与时间曲线，不靠物理模拟 |

## 十二、原型已经跑出来了（2026-11-16 实况）

设计稿写完先做了个判断：**SVG 手绘的方向板到不了「不可能」**——桥是平的，像剪纸，因为平视正投影本身没有纵深。所以我没有继续修示意图，直接写了真正的 3D 原型。

产物：`赵州桥_原型.html`（43 KB，双击即开）

### 已经做到的

| 项 | 实况 |
|---|---|
| 桥体 | 主拱按真实尺寸参数化（净跨 37.02 / 矢高 7.23 / 桥宽 9.6），三点定圆，26 段 × 12 道拱券石块 |
| 敞肩四小拱 | 拱肩左右各两个，洞口由砌体挖空形成，不是贴上去的洞 |
| 栏板望柱 | 21 组，带灯笼与点光 |
| 两岸 | 程序化生成的缓坡 + 22 棵岸树，桥不再浮在水上 |
| 开场 | 15 秒一条相机轨迹：中景 → 压到水面（桥洞框月）→ 拉升环绕；石块从水下升起拼合，2.6 秒完成 |
| 氛围 | 程序化星空 2600 点、月亮（纯 shader）、水面顶点位移 + 有限差分法线、月光水柱、四层雾、萤火虫 |

### 调试参数（改效果用，不用改代码）

- `?seek=9.5` 把画面定格在第 9.5 秒，调镜头就靠它
- `?hide=fog,flies,beam,stars,inst,water,banks,trees` 逐个关掉对象排查
- `?flat=1` 关掉水面起伏

### 已知短板（按优先级）

1. **依赖 CDN**——现在从 unpkg 取 three.js，断网打不开。要真正「单文件断网可用」，下一步把 three.js 内联进去（gzip 后约 55 KB，整包可控制在 400 KB 内）。
2. **腹墙还是一大片平灰面**——缺砌缝深度和石材凹凸，近看会露馅。下一步给石材加程序化法线扰动。
3. **桥洞内是死黑**——没有间接光，真实感差一截。
4. **水面没有真倒影**——现在只有月光水柱。真倒影要加一次镜像渲染，代价是帧率。
5. 栏板浮雕是空的，只有素板。

### 调这些参数时踩过的坑（省下次的时间）

- GLSL 的 `smoothstep(edge0, edge1, x)` **参数写反是未定义行为**，SwiftShader 会算出 NaN，画面上表现为随机的黑斑。本文件里六处都踩过。
- `pow(负数, 非整数)` 也是 NaN，`1.0 - vUv.y` 在边界会取到负数。
- 材质没有环境贴图时，`metalness` 设高会让表面算成黑色（水面那块板就是这么黑的）。
- 传给石块颜色的 `tint` 漏传成 `null`，`数字 * null = 0`，那一块就是纯黑——桥上的黑三角是这么来的，不是几何问题。
- 顶点位移了但**不重算法线**，水面只有形状没有明暗，看起来像一块蓝布。要在 `beginnormal_vertex` 里用有限差分补上。
