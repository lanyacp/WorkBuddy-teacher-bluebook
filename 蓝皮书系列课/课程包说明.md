## 二、怎么用（开录顺序）

1. **先定路线**：看 `课程地图.png`，按路径 A（一线教师 20 讲 / 8.6 h）或路径 B（组长 12 讲 / 4.3 h）。
2. **再补素材**：按清单的 **P0 共 11 项**先补（`V-00-01～04`、`V-01-01`、`V-01-02`、`V-02-01`、`V-03-01`、`S-02-01`、`S-02-02`、`S-03-01`），放进 `待补素材/`，把状态列改成 ✅。
3. **替换留白**：PPT 与课件小样里所有灰底框按编号换成图片；**没补完也能先录口播**。
4. **录样片**：先录 01（S）、05（R）、13（L）三种类型各一条；本包前四节可直接从 00 开始录。
5. **注意静音段**：02 的 **10:00–20:00**、03 的 **12:00–22:00** 是留给学员自己动手的，画面定格、不讲话、不加新信息。

## 三、PPT 用法

- 34 页 16:9，**第 1–2 页**是课程包总览，**第 3–10 / 11–18 / 19–26 / 27–34 页**分别是 00 / 01 / 02 / 03 的 P1–P8。
- 深蓝＝封面与红线页，橙色＝暂停跟做页，灰底虚线框＝待补素材位。
- 改文案：编辑 `slides/{NN}.slide` 后重新写回 PPT 对应页；或直接在 PowerPoint 里改。
- 放映时留白框保持原样也没关系，讲师按脚本口播即可。

## 四、这一版的课程设计口径

- **时长给跟做，不给讲解**：全季含跟做 11 h，讲解净时长 ≈5.8 h（与 v1 持平）。
- **每讲内容配额**：1 个成品 / 1 句原理 ≤25 字 / ≤3 条踩坑 / 1 条指令 / 1 条红线 / ≤2 个新术语，并写明「本讲不讲」。
- **结构按 Kolb 四段 + P6 强制暂停点**；起点按一线教师真实基础设定，不假设会命令行、装环境、看报错、配 API Key。

## 五、边界

- 未调用任何外部 API，未上传肖像或声纹，未做提交、推送、飞书同步——按项目一贯规矩等你确认。
- 素材一律用示例教案与虚构数据；不出现真实学生姓名、成绩、作文原文。
- 界面按录制当天当期版本补拍，不用蓝皮书里标 ⚠️ 的旧截图。
