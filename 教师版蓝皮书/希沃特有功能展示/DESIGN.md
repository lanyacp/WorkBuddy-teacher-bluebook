# 希沃特有功能展示 · 设计方案

> 面向：中小学教师 / 教研培训现场
> 目标：说清「用 WorkBuddy 直接做希沃课件」的价值，重点展示希沃原生可交互组件（汉字卡、思维导图、课堂互动游戏），并交付可执行的操作与检查清单
> 页数：10 页｜风格路由：通用（general.md）｜叙事：价值 → 三大功能 → 怎么做 → 怎么查 → 怎么沉淀

## 一、全局视觉约定

### ① 画布与安全区

- 画布 1280 × 720（16:9）
- padding：上下 60px / 左右 60px（硬下限）
- 内容区 1160 × 600
- 页脚固定在 y = 670：左「希沃白板 · 特有功能」14px，右页码 14px；封面 / 结尾页不加页脚

### ② 配色方案（教育暖橙，全篇只用这一套）

| 槽位 | Hex | 用途 |
|---|---|---|
| 主色 | `#EA580C` | 标题细线、编号块、强调条、深色块底色（深调 `#C2410C`） |
| 辅色 | `#FDBA74` | 卡片浅底、标签、图示第二层 |
| 强调色 | `#0EA5E9` | 关键数字、核心标注、交互提示（一页 2-3 处） |
| 底色 | `#FFF7ED` | 主背景 |
| 正文色 | `#1C1917` | 主文字 |
| 中性 | `#FFFFFF` / `#E7E5E4` / `#78716C` | 卡片底 / 1px 细线 / 辅助说明 |

色彩纪律：主色 ≤60%、辅色 ≤30%、强调色 ≤10%；深色大块每页 ≤1；全篇禁用阴影，层次靠底色 + 1px 线 + 留白；圆角统一 8px。

### ③ 字体系统

- 中文：Microsoft YaHei（雅黑）；西文：Arial；全篇只此一组
- 字号阶梯：封面主标 76 / 巨型数据 96 / 页面主标 36 / 卡片小标 24 / 正文 18 / 注释·页脚 14
- 任意可见文本 ≥14px；正文行高 1.5；同页「字体+字号+字重」组合 ≤4 种

### ④ 视觉母题

- **页面主标题下 1px 贯通细线**（主色 `#EA580C`），内容页固定位置；标题顶边贴 y = 60
- 统一的**橙色圆角编号块**（01 / 02 / 03…）用于功能与流程节点
- 页脚左眉标 + 右页码，全篇位置不漂移

### ⑤ 配图清单

| 文件 | 等级 | 生成方式 | 真实内容 | 使用页 |
|---|---|---|---|---|
| `assets/seewo_3fix.png` | L2 | material（蓝皮书自制归因图） | 三个问题的归因与解法：对比度 / 背景丢失 / 表格越界 | 教程 HTML 阅读版（PPT 内改用重排文字，见下方说明） |
| 组件界面示意 | L1 | SVG + Box（结构化图形） | 汉字卡、思维导图、判断对错 PK 的界面结构示意 | P4 / P5 / P6 |

第 8 页原计划放 `seewo_3fix.png`（1080×608 横版、内含小字），但缩到 PPT 半幅后小字不可读，改为**三条归因文字重排**（现象 / 原因 / 解法各一行，18px 起）。原图保留在教程 HTML 阅读版中作为可放大的证据图，PPT 只承担投影可读性。

## 三、节奏与版式自检

- Hero 页：P1 / P3 / P6 / P10（4 页 / 10 页 = 40%，略高于 20-30%，但教程型 deck 封面与结尾默认 Hero，P3、P6 为中段高潮；P3→P6 之间隔 P4、P5，不相邻）
- 非对称版式：P1 / P2 / P3 / P4 / P5 / P6 / P8 / P9 / P10 ≥ 40%
- 等宽卡片横排：全篇 0 次
- 相邻页版式均不同：大字报 → 对比式 → 巨型数字 → 左图右文 → 上图下文 → 深色块+示意 → 流程链 → 左标题色块 → 独白+编号 → 金句
- 内容页标题位置、页脚位置全篇一致；封面 / 结尾不加页脚
- 每页均有视觉锚点；每块均有一眼可见的结论句
