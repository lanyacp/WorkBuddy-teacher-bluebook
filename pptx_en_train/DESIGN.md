# DESIGN.md — AI 赋能英语教学 3 小时培训课程设计（PPT 设计稿）

## 0. 项目定位
- 类型：教师培训课件（培训课件 → 通用设计原则，落地教育气质）
- 受众：县乡一线初中英语教师
- 气质：专业、温暖、可落地；与源 Word 文档（C_MAIN 1A5F7A / C_GREEN 2E7D32 / C_ORANGE F57C00）品牌一致

## 1. 画布与母版（默认三区）
- 画布：1280×720，16:9
- A 标题块：0–120px（主标题 32-38px bold，含上 padding 20）
- B 内容区：120–660px（540px 可用）
- C 页脚条：660–720px（左：项目简称"AI 赋能英语教学·课标锚定版"；右：页码 `NN / 15`，14px 灰）
- 页面 padding：上下 20px、左右 64px
- 封面/结束页可自定义版式、省略 C 区

## 2. 颜色系统（≤4 主色 + 中性）
| 角色 | hex | 用途 |
|---|---|---|
| 主色 main | `#1A5F7A` | 标题栏底色、大色块、hero 背景、强调结构 |
| 辅色 secondary | `#2E7D32` | 卡片头、第二系列、成功/产出色 |
| 强调色 accent | `#F57C00` | 巨型数字、焦点标注、CTA、核心数据（≤10%，hero≤18%） |
| 警示/痛点 | `#C0392B` | 痛点原声、风险标注（克制使用，不计入主 4 色，作语义色） |
| 文本 | `#1F2937` 主 / `#5B6B7B` 次 | 正文、页脚 |
| 背景 | `#FFFFFF` / `#F4F8FA` 浅底 | 页面底、卡片底 |

色彩面积分配：
- Hero 页：主色 50-60% + 辅色 20% + 强调色 12-18%
- Supporting 页：主色 35-45% + 辅色 15-20% + 强调色 ≤5%
- 渐变：允许 `linear-gradient(135deg, #1A5F7A 0%, #2E7D32 100%)` 用于 hero 标题栏/封面主视觉；半透明 `rgba(26,95,122,0.08)` 铺底
- 禁止：同页 ≥2 套主色板；全篇每页色比雷同

## 3. 字体系统
| 层级 | 字号 | 字重 | 字体 | 用途 |
|---|---|---|---|---|
| 封面主标题 | 64 | bold | `Microsoft YaHei` | 仅封面 |
| 章节/hero 大字 | 54-72 | bold | `Microsoft YaHei` | hero 主视觉 |
| 巨型数字/锚点 | 72-110 | bold | `Arial` | 核心数字（与正文不同字体） |
| 页面主标题 | 34 | bold | `Microsoft YaHei` | A 区固定 |
| 卡片小标题 | 24-26 | 600 | `Microsoft YaHei` | 卡片头 |
| 正文 | 21-23 | normal | `Microsoft YaHei` | 段落 |
| 引文/原声 | 19-21 | italic | `Microsoft YaHei` | 「」一线原声 |
| 脚注/页码 | 14 | normal | `Microsoft YaHei` | 页脚 |

## 4. 信息密度
- 常规内容页留白 ≤35%；卡片填充率 ≥85%（高卡≥380px 时正文≥100字）
- 每页≥1 视觉锚点（≥44px 元素或 ≥40% B 区面积图）
- 图标：用 FAIcon（如 book、users、lightbulb、gamepad、comments、check-circle、clock）

## 5. 配图策略（本项目声明）
- 本项目为抽象培训方法论，视觉锚点以 **SVG 结构图 + 巨型数字 + 大色块** 实现（时间轴、四维矩阵、四要素卡、流程图均为 SVG/类型锚点，符合"结构化/低语义用 SVG"规则）。
- 不引入摄影类 L1 图，避免风格混杂与版权/生图不确定性。
- 全程仅 1 套配色、1 套字体家族（+Arial 数字），保持品牌一致。
