## 二、按章节逐条落位

### 第一篇·工具入门

**第3章 安装登录 / 第4章 界面与工作区 —— 设置地图（P1）**

两篇文章的设置侧栏一致：`通用 / 个人主页 / 套餐与积分 / 外观 / 快捷键 / 功能（个性化·记忆与进化·智能体·模型·助理·设备连接·对话流）/ 数据与安全（数据导入·数据管理·应用管理·安全中心）`。

第1课时必讲的 6 类设置（来自两篇实测）：
1. **自定义指令**——入口：设置→个性化→给 WorkBuddy 的指令。原文模板："收到任务后，不要立刻执行，先确认四件事：想解决什么 / 交付什么 / 必须遵守的限制 / 怎样才算完成"，并明确"嗯""行吧"不算确认。这段正是你 B2 万能指令骨架、B3 四要素自检的原型出处，可标注来源。
2. **记忆与进化**——云端记忆、本地记忆，技能分用户级/项目级。
3. **模型档位**——快速 0.15x / 均衡 0.5x / 极致，上下文窗口 1M、思考强度；一任务一新会话。
4. **安全中心**——自动备份 + 沙箱限制文件夹读写。
5. **个性化**——称呼、名字、回复风格、人设。
6. **对话流**——欢迎语、显示文件修改过程、队列发送方式。

⚠️ **核对提醒**：两篇均未出现"缓存""工作文件夹"，无法印证"不在通用页"的判断；你之前按真实截图确认过，以你的截图为准，但**别把重心放在缓存项**，这几篇文章都指向上面 6 项。

来源：《花2分钟做好WorkBuddy这5类设置》《简单设置，立刻让WorkBuddy聪明百倍》

**第8章 课件 —— 交互课件的出场时机（P0，教学法原则）

这批文章里最有教学价值的一条，补的是你课件章缺的「什么时候别用」。

- 核心主张：交互课件要"忍一忍，憋出学生需求"，忌开门见山。
- 四步节奏：PPT/希沃抛问题 → 猜想试错 → 等分歧/卡壳产生验证需求 → 才放 HTML 课件动态验证。
- 四个出场时机：想象不出、答案分歧、语言讲不透、需验证猜想。
- 三个禁区：导入炫技泄结论、整节挂机分散注意、替代教师引导。
- 口诀："平时不用，卡点才用；先憋需求，再给答案"。
- 搭配原则：主线仍用希沃/PPT，HTML 只做"破局工具"。

来源：《别再乱用HTML交互课件！优秀的数字化课堂，都懂得"忍一忍"》

**第19章 教师培训与微课 —— 数字人选型与边界（P0）**

|---|---|---|

## 四、一个跨批次的方法论补充（建议写进附录或第24章）

这批文章反复出现两种「用好 AI」的范式，值得单列：
