**P3 回想 + 选型**

**P4 一句原理 + 路径**
- 原理（全屏大字）：**先给计划，再让它动手**
- 五步：装好 → 建工作区目录 → 提第一个任务 → 二次修改 → 追问

**P5 教师演示（一镜到底，≤3 张截屏位）**
- **【待补｜V-02-01】** 3 分钟录屏，三段各约 1 分钟：
  1. 提任务 → 它先给计划
  2. 确认 → 生成 → 文件落盘

- **【待补｜S-02-03】** 第 1 段「计划」那一屏
- **【待补｜S-02-04】** 第 3 段「二次修改前后对照」那一屏

**P6 暂停跟做（本讲最重要的一页）**
- 大字（64–80px，深色或橙底）：**现在暂停，自己动手**
- 三步（每步 ≤12 字）：
  1. 建一个自己的工作区文件夹
  2. 用示例教案提第一个任务
  3. 说一次「其它别动」
- **卡住怎么办**（必须原样念）：① 看文件夹里有没有出现新文件　② 没出现就重提一次任务　③ 实在不行，直接打开示例文件手动改，**允许跳过，不卡进度**
- 做完的标志：**文件夹里出现成品，双击能打开，原件没被覆盖**
- 保底方案：普通 PPT / 现成模板顶上
- 口播（8:40–10:00）：「接下来 10 分钟我不说话。你按这三步做一遍，做完回来对一下标志。卡住就走第三步，别硬扛。」

**P7 交付 + 验收**

- 3 条验收：① 说得出每份产物在哪个文件夹　② 修改只改了指定那一处　③ 示例原件未被覆盖
- 踩坑（≤3 条）：不建目录，产物找不到 / 一上来就下最终指令 / 修改时不说「其它别动」

## 逐页文案

**P1 封面**
- 主标题：会下指令，更要会装 Skill
- 副题：这讲解决你哪个麻烦——每次都要把同一段要求重新说一遍，或者装了一堆却总选错
- 口播：「这讲只装一个，不装一堆。判断标准就一句话：这件事你做过三次以上没有。」

**P2 成片先行**
- 叠字：「装一次，以后这句话就不用再打一遍」
- **【待补｜S-03-01】** 一个教学 Skill 跑通后生成的成品（建议用一份导学案），要能看清是「一份文件」而不是一段对话
- 口播：「别管它叫什么，你看结果——一份能直接打开、能改的文件。」

**P3 回想 + 选型**
- 左栏大字：**同一段要求，你是不是每次都重新说一遍？**
- 左栏小字：复制上次的提示词 / 换个班又重说 / 存到哪儿忘了
- 右栏「用」：重复做过 3 次以上的流程 / 每次格式都一样
- 右栏「别用」：一次性任务 / 随手装一堆攒着
- 口播：「原来的做法没问题，只是费记性。装一个，就是把这段记性交给它。」

**P4 一句原理 + 路径**
- 原理（全屏大字）：**重复三次的流程才值得装成技能**
- 五步：找入口 → 搜一个本学科教学 Skill → 看说明 → 只装 1 个 → 立刻跑一遍
- 指令条（唯一一条）：`用我刚装好的那个 Skill，把附件里的示例教案整理成一份导学案`
- 口播补一句：「如果它要你点一下技能气泡再说话，就点一下，这句话不用改。」
- 口播：「看说明只看一件事——它管哪一段、不管哪一段。别看功能列表有多长。」

**P5 教师演示（一镜到底，≤3 张截屏位）**
- **【待补｜V-03-01】** 90 秒录屏：找入口 → 搜（建议搜「教学」或本学科名）→ 看说明 → 装 1 个 → 用示例教案跑一遍
- **【待补｜S-03-02】** 技能市场里搜到那 1 个 Skill 的一屏
- **【待补｜S-03-03】** 「已启用」那一屏
- 口播三点：① 只装一个　② 先看说明里管哪一段　③ **装完立刻跑一遍，别攒着**
- 不跳剪；失败别剪，压进 P7 踩坑

**P6 暂停跟做（橙底，本讲最重要的一页）**
- 大字（64–80px）：**现在暂停，自己动手**
- 三步（每步 ≤12 字）：① 搜一个本学科教学 Skill　② 只装 1 个　③ 用示例教案跑一遍
- **卡住怎么办**（原样念）：① 看它是不是显示「已启用」　② 没启用就重装一次　③ 实在不行，用 02 讲那条普通指令顶上，**允许跳过，不卡进度**
- 做完的标志：**能说出这个 Skill 管哪一段、不管哪一段，并且手里有一份能打开的文件**
- 保底方案：普通指令 / 现成模板
- 12:00–22:00：P6 定格 + 三步小字常驻，不加新信息

**P7 交付 + 验收**
- 交付（1 个）：装好并跑通的 1 个教学 Skill + 一份生成文件
- 3 条验收：① 说得出它管哪一段　② 生成文件能打开　③ 没有一口气装一堆
- 踩坑（≤3 条）：备课类 Skill 各管一段别混用 / 「出作业」不等于「批作业」/ 装完不跑，下次还是不会用
- **【待补｜S-03-04】**（可选）：学员做完应该长什么样的对照样张
- 口播：「29 个 Skill 的全景图在讲义里，课上不念。你只装一个就够；装多了反而选错。」

**P8 红线 + 回想**
- 红线原文：**Skill 输出也要人工核验**
- 下周在哪用：下次用它生成材料后，自己先通读一遍再发
- 预告：下一讲 04 通用文件助手，左边看文件、右边说改哪里

## 四节课共同的收尾纪律

1. **讲解超时就剪**，不许挤占 02 讲那 10 分钟跟做时间。
