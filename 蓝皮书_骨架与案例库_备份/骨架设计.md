# 《WorkBuddy 教师实战蓝皮书》· 骨架设计

> 原项目 AlephAITech/WorkBuddyGuide 结构：4 篇 27 章 + 2 附录，VitePress 站点。
> 本书沿用其**体例**（痛点 → 五问工作流 → Skill 表 → 分类型展开（流程表+提示词+验收）→ 常见错误表），但**内容全部换成教师场景**。
> 体例采样自原书第 11 章（办公三件套）、第 26 章（岗位路线图），其核心特征是：每处都写"人要确认什么"和"安全边界"。

## 定位差异

| 维度 | 原蓝皮书 | 教师版 |
|---|---|---|
| 读者 | 职场人、白领、创作者 | 县域中小学教师、教研员、校长 |
| 主线 | 从一项任务到一支 AI 团队 | 从一个班到一所学校的工作流 |
| 案例 | 办公、投资、自媒体、GEO | 备课、批改、学情、教研、家校、行政 |
| 红线 | 商业机密、客户数据 | 学生个人信息、试题、评价结论 |
| 验收 | 交付可用、风险可控 | 符合课标、可追溯教材、教研组能复用 |

## 章节结构（26 章 + 3 附录）

### 第一篇 · 先把工具用起来（6 章）
1. 这本蓝皮书怎么用
2. 认识 WorkBuddy：它和豆包、DeepSeek 有什么不一样
3. 安装、登录与第一个任务
4. 界面与工作区：会对话，更要会下指令
5. 加载一个真正用得上的 Skill
6. 让它记住你的要求：指令骨架与四要素

### 第二篇 · 教学全流程工作流（9 章）
7. 备课：一份能直接用的教学设计
8. 课件：从教案到能投屏的 PPT
9. 作业与练习：分层设计而不是一份到底
10. 出卷与试题库：一次生成整套卷子
11. 批改与学情分析：从凭感觉到看数据
12. 错题本：让错题真的能被再用一次
13. 阅读与写作：语文学科的两个深水区
14. 英语听说与词汇：开口难怎么破
15. 理化生实验与图表：理科教师怎么用
16. 家校共育：家长会、沟通话术与家长学校

### 第三篇 · 教研、行政与成长（6 章）
17. 教研：从个人备课到教研组共用
18. 听评课与课堂观察：让数据代替感觉
19. 教师培训与微课：把会的东西变成课
20. 行政文书：通知、计划、总结、简报
21. 课题与论文：选题、提纲、文献综述
22. 校本档案与教师成长记录

### 第四篇 · 进阶：把工具变成你的系统（4 章）
23. 自动化：把每天都要做的事交给它
24. 打造属于你的 Skill
25. 多 Agent 与专家团：一个教研组配一支 AI 团队
26. 从个人到区域：把工作流交给学校

### 附录
- 附录 A 常用指令模板（按学科与场景分类）
- 附录 B 场景速查表（我要做什么 → 先看哪一章 → 提示词在哪）
- 附录 C 红线清单：教育部《指引》六类行为规范 + 学生使用指南 + 本地安全底线
