### 改稿流程

```bash
# 0. 暂存（重要：这一步会自动排除不该入库的内容）
bash stage_for_commit.sh

# 1. 改完分篇 md 后，重新生成合并版
cd 教师版蓝皮书
python build_official.py        # 生成正式版（对外）
python build_bluebook.py        # 生成完整版（内部，含案例库）

# 2. 检查配图有没有断链
cd ..
python check_images.py# 输出各文件图片引用 N/N

# 3. 提交
git add 教师版蓝皮书/
git commit -m "改稿：说明改了什么"
git push
```

> **⚠️ 为什么必须用 `stage_for_commit.sh` 而不是直接 `git add -A`？**
>
> **`.gitignore` 对顶层中文目录名匹配不可靠**——`英语课程资料/` 这种顶层中文目录
> 每次 `git add -A` 都会被加回来（337MB 的他人版权教材）。
>
> 脚本用 Python 处理路径列表绕开命令行中文编码问题，显式 `git rm --cached` 移除。
> **这是本仓库唯一的安全网，不要跳过。**

### 配图替换（重要）

**正文里凡是标了 ⚠️ 的地方都是已知会过时的地方**（产品迭代快，平均三天一版）。

替换步骤：

1. 把新截图放进 `教师版蓝皮书/assets_opt/`，**文件名和原来一致**（覆盖）
   - 或者改md 里的 `![](assets_opt/xxx.png)` 指向新文件名
2. 跑 `python check_images.py` 确认不断链
3. 重新执行 `build_official.py`
4. 重新推送到飞书（见下）

**图片命名不要用 `default` / `placeholder` / `sample` 这类词**，
否则会与占位图检测脚本冲突（见 `verify_feishu_images.py`）。

### 推送到飞书

**带图片的 Markdown 推飞书必须走专用脚本**，直接用飞书导入会变成 22KB 占位图。

```bash
# 单篇推送（约 5 分钟 / 60 张图）
python push_to_feishu.py 教师版蓝皮书/第一篇_先把工具用起来.md "01 第一篇 先把工具用起来"

# 验证图片是不是真图（不是占位图）
python verify_feishu_images.py <飞书文档token>
```

**踩坑结论（已验证，勿推翻）：**

| 方式 | 结果 |
|---|---|
| `drive +import` | ❌ 文字正常，图片变 22KB 占位图 |
| `docs +create --doc-format markdown` | ❌ 图片直接丢弃 |
| `docs +create` 传 XML `<img path>` | ❌ 图片丢弃 |
| **`docs +media-insert` + `block_move_after`** | ✅ 唯一可靠路径 |

## 四、脚本速查

| 脚本 | 用途 |
|---|---|
| `push_to_feishu.py` | 带图片的 md → 飞书（唯一可靠路径） |
| `verify_feishu_images.py` | 校验飞书文档图片是否为真图 |
| `check_images.py` | 检查本地 md 图片引用是否断裂 |
| `clean_penguin_shots.py` | 界面截图脱敏第一轮（填侧边栏分区文字） |
| `deep_clean_shots.py` | 界面截图脱敏第二轮（整条侧边栏填平 + 面板挖回） |
| `clean_personal_info.py` | 界面截图脱敏第三轮（抹使用时长 / 模型名 / 活动弹窗） |
| **`audit_images.py`** | **配图隐私体检报告（开源前必跑）** |
| `extract_pdf_images.py` | 从PDF 批量提取图片 |
| `教师版蓝皮书/build_official.py` | 生成对外交付的正式版（含 `PUBLIC_MODE` 开关） |
| `教师版蓝皮书/build_bluebook.py` | 生成含内部稿的完整版 |
| `grab_window.py` | 抓本机 WorkBuddy 窗口截图（Electron 需 `PW_RENDERFULLCONTENT`） |

### 截图脱敏的三层流程（顺序不能颠倒）

```bash
python clean_penguin_shots.py    # 第一轮：填侧边栏分区
python deep_clean_shots.py# 第二轮：整条侧边栏填平 + 菜单面板挖回
python clean_personal_info.py    # 第三轮：抹使用时长 / 模型名 / 活动弹窗
```

**踩过的坑（照着做能省时间）：**

| 坑 | 现象 | 正确做法 |
|---|---|---|
| 分区填充漏区域 | 侧边栏底部「实习」标签没清掉 | **整条填平**，别按分区画矩形 |
| 云纹背景不能用白块 | 填白色后在深色背景上留下明显白块 | 用**云色渐变**过渡，或**直接裁掉**非教学重点区域 |
| 模型名位置各图不同 | 硬编码坐标导致漏清 | **扫描深色像素自动定位**包围盒 |
| 废弃截图残留 | 从未引用的抓图被一起提交 | 提交前查引用，删掉未引用文件 |
