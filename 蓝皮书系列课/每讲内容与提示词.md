# 每讲内容与提示词（第一季）

> **用途**：把「这一讲讲什么」和「这一讲要用哪几条提示词」绑在同一个模块里。备课时翻这一份就够，不用再去附录里翻找。
> **编号**：`T-讲次-序号` 是课上主提示词；`A-xx` / `U-x` 是蓝皮书 `附录A_常用指令模板.md` 里的完整模板编号；专题提示词按 `专题_XX.md` 的章节定位。
> **纪律**：一讲只挂 **1 条主提示词**（写在课件 P4，可原样粘进对话框），其余只给编号；带 `【】` 的方括号**必须换成真实信息**再发给学员，不许把占位符当成品；涉及学生材料的讲次一律加 `U-6`。
> **顺序说明**：讲次编号沿用 `课程大纲_第一季.md` v2（00–25）。**当前录制用的第 1 课时已改为「装好 WorkBuddy，把该设的先设好」**，作为 ★ 单列在 M1 开头；等后面几讲要点给齐再统一顺延编号。

## M1　地基

### ★ 当前录制用第 1 课时　装好 WorkBuddy，把该设的先设好（L · 32 min）
**讲什么**：下载安装、面板三块、设置里只碰「文件打开方式」「字体大小」，权限区看一眼、「模型」「数据管理」只认位置｜**成品**：工作文件夹 + 「我的设置」清单

**主提示词 `T-01A-1`**（P4，逐字稿在用）：
```
帮我把当前工作区的位置告诉我，并列出我可以改的三项基础设置
```
**配套**：`A-0-7` 只读分析绝不改文件（讲「保存会覆盖原文件」时用）；`A-0-1` 改一份已有文件（第 3 课时预习）
**本讲不讲**：模型参数、快捷键、个性化、记忆与进化、智能体、助理、设备连接、对话流、数据导入、网络代理、开机自启动

### 01　对话框，和工作区差在哪（S · 14 min）
**讲什么**：同一个模型、同一个任务，对话框给文字、工作区给文件｜**成品**：一句话差别 + 第一个落盘任务

**主提示词 `T-01-1`**（P4）：
```
先给计划，别直接动手
```
**完整模板 `U-5` 先看计划再执行**（备查，讲义里给全文）：
```
请先给我一份"材料清单"或"执行计划"，我确认后再生成文件。
清单里要写清：1. 有哪几项，各自解决什么 2. 每项的页数/字数/格式
3. 你需要我回答什么问题 4. 有哪些信息工作区里没有、要标为"待确认"
5. 输出的文件路径和命名。我确认后再开始生成。
```

### 02　装好、连上、跑通第一个任务（R · 22 min）
**讲什么**：三层对话——先给计划、再改一处、最后追问｜**成品**：工作区目录 + 一次完整三层对话

**主提示词 `T-02-1`**（P4 / P6）：
```
把刚才那份改成分栏，其它别动
```
**完整模板 `U-4` 二次修改**：`不要重新生成。在上一版基础上改：1.【具体问题→改成什么】… 约束：【不能动的内容】改完列一个修改清单，其他内容不要动。`
**配套**：`U-3` 追问四招、`U-1` 万能骨架

### 03　会下指令，更要会装 Skill（R · 24 min）
**讲什么**：重复三次的流程才值得装；只装 1 个、装完立刻跑一遍｜**成品**：装好并跑通的 1 个教学 Skill + 一份生成文件

**主提示词 `T-03-1`**（P4）：
```
用我刚装好的那个 Skill，把附件里的示例教案整理成一份导学案
```
**配套**：`A-29` 做自己的 Skill（**第二季**才用，本讲只指位置，不展开）

### 04　通用文件助手（L · 32 min）
**讲什么**：左边看文件、右边说改哪里；Word/Excel/PPT/PDF 通用｜**成品**：教案 → 导学案

**主提示词 `T-04-1`**（P4）：
```
按附件格式，把这份教案改成一份学生学习任务单；只改格式与栏目，不要改我写的内容
```
**配套模板（本讲最集中）**：`A-0-1` 改一份已有文件、`A-0-2` 没说选中范围时先确认、`A-0-3` 只要建议不要动文件、`A-0-4` 按格式统一排版、`A-0-5` 从这份材料接着做下一份、`A-0-6` 改网页课件、`A-0-7` 只读不改
**必加**：`U-6` 数据安全条款（见文末红线提示词）

## M2　教学全流程（一周备课闭环）

### 05　一份能直接用的教学设计（R · 26 min）
**讲什么**：目标里必须有看得见的行为动词｜**成品**：一份教学设计
**主提示词 `T-05-1`**（P4，节选自 `A-1`）：
```
我是【学科】老师，教【年级】。请按附件里课标与教材第【X-X】页，
准备【单元名称】的教学设计：每条目标含可观测动词 + 对应课标条目，
分层任务 3 档，不确定的标"待我确认"。
先出目录和结构划分，我确认后再生成 Word。
```
**配套**：`A-1` 单元教学设计、`A-2` 公开课九件套、`A-3` 教案二次修改、`U-1` 万能骨架

### 06　从教案到能投屏的课件（R · 22 min）
**讲什么**：一页一句话、字号不小于 24pt｜**成品**：8 页课件
**主提示词 `T-06-1`**（P4，课程自撰，骨架取 `U-1`）：
```
按这份教学设计做 8 页课件：每页一个核心结论、正文不超过 80 字、
字号不小于 24pt，其余内容放备注。先给页序清单，我确认后再生成。
```
**配套**：`A-2` 里的 PPT 要求、`U-5` 先看计划再执行

### 07　分层作业（R · 22 min）
**讲什么**：变式四式，换情境不只是换数字｜**成品**：A/B/C 三层作业
**主提示词 `T-07-1`**（P4，节选自 `A-4`）：
```
请设计【课题】的分层作业：3 档共【N】题，每题标考查知识点；
基础档只给 1-2 句思路提示、不给答案；难度梯度要真能分出档，不超纲。
先出"知识点—题量—难度"对应表和题干（不含答案），我确认后再出答案。
```
**配套**：`A-4` 分层作业、`A-5` 变式题生成、`A-11` 错题同类题专项

### 08　出卷与等值性检查（R · 24 min）
**讲什么**：先定细目表，再出题｜**成品**：一套卷 + 双向细目表
**主提示词 `T-08-1`**（P4，节选自 `A-6`）：
```
请先出一份双向细目表（不要出题）：知识点 × 题型 × 分值，难度比例 7:2:1。
我确认细目表后再出题；生成后交叉核对题号、答案编号、总分、有无超纲题。
```
**配套**：`A-6` 期中/期末试卷、`A-7` 校本试题库整理

### 09　批改与学情（R · 26 min）
**讲什么**：分数给对了、理由可能写错了；五类风险复核｜**成品**：批改结果 + 人工复核清单
**主提示词 `T-09-1`**（P4，**必须整段加 `U-6`**，节选自 `A-8`）：
```
【数据处理要求】全程本地处理、只出现学号、不改动原始文件、识别不清标"待人工核对"。
请先输出识别方案、分类方案、表格字段设计，等我确认再执行；
评语必须引用学生原句并指出在第几句，禁止"语言优美""结构完整"这类空话。
```
**配套**：`A-8` 批改与学情、`U-6` 数据安全条款、`A-9` 讲评课设计
**红线**：错题成因栏留空给教师填

### 10　错题本与讲评（R · 22 min）
**讲什么**：按错因分组，不按题号｜**成品**：错题本 + 讲评 HTML
**主提示词 `T-10-1`**（P4，节选自 `A-10`）：
```
把本周错题做成卡片：原题重排、考查知识点、错因归五类之一、
一句"下次怎么避免"、配 1 道同类题。另出班级错因分析，只出现学号。
```
**配套**：`A-10` 错题本批量生成、`A-11` 同类题专项、`A-12` 错题本「用一次」机制、`A-9` 讲评课设计

### 11　学科专项三选一（R · 26 min）
**讲什么**：只做自己那一科，另外两科不念｜**成品**：本学科一个可用片段
**主提示词按学科给一条**（P4）：

| 学科 | 主提示词（节选） | 完整模板 |
|---|---|---|
| 语文 | `按难度分三档设计设问点，每个写清学生的回答可能分几个层次、只答到第一层时追问什么。不要生成"标准答案式的文学鉴赏结论"。` | `A-13`、`A-14` |
| 英语 | `设计听说任务包：3 个情境脚本、每档标"必说/可选"，附降级方案。只陪练，不设计打分、评级、排名。` | `A-15`、`A-16` |
| 理化生 | `严格使用我给的器材清单设计实验方案，报告单要有多次测量与误差计算；异常值标出来让我决定，不要自动删除。` | `A-17`、`A-18` |

### 12　家校共育 + 一周闭环复盘（R · 22 min）
**讲什么**：发给家长的那段话必须自己写｜**成品**：家长话术 + 一周工作流图
**主提示词 `T-12-1`**（P4，节选自 `A-33`）：
```
请生成家长会发言稿与一页学情反馈单：不出现任何学生姓名、成绩组合，
"我做的三件事"和"请家长配合的三件事"分开列，讲家长该做什么要具体到动作。
```
**配套**：`A-33` 家长会材料、`A-25` 学期总结（含「不要虚构我没说的事」）
**红线**：关键段落由教师本人写，不由模型代笔

## M5　管理轨

### 19　教研组共用（R · 22 min）
**讲什么**：只统一输入与交付格式，过程各自保留｜**成品**：共用清单
**主提示词 `T-19-1`**（P4，节选自 `A-19`）：
```
教学设计中必须明确区分【必须统一】的部分（目标、重难点、课时分配、基础检测）
与【可自行调整】的部分（例子、生活情境、活动形式、作业难度）。这一条最重要。
```
**配套**：`A-19` 教研组单元集体备课、`A-23` 校本研修方案（多专家）

### 20　听评课与课堂观察（R · 20 min）
**讲什么**：手工观察 6 项是上限｜**成品**：6 项观察表
**主提示词 `T-20-1`**（P4，节选自 `A-20`）：
```
观察项只用这 6 项，手工可记录，表不超过 A4 一页；
建议要具体到"下次哪个环节改成什么动作"，不要写"加强引导"这类空话；
数据不足以得出结论时，直接说"数据不足"。
```
**配套**：`A-20` 课堂观察与诊断、`A-22` 教研组观察标准流程、`A-21` 同课异构对比

### 21　教师培训：把会的东西变成课（L · 36 min）
**讲什么**：按老师的一天讲，不按工具讲｜**成品**：90 min 培训脚本 + 失败预案
**主提示词 `T-21-1`**（P4，节选自 `A-35`）：
```
不做工具功能讲解，做工作流讲解；要有一个"疑虑回应"模块，
专门回应"会不会让我变懒""学生信息能不能给它""会不会取代我"这几个疑问。
培训后每位学员要能独立完成一次完整任务并带走一份成品。
```
**配套**：`A-35` 教师培训全套材料、`A-36` 微课系列设计、`附录E_2026年10月补遗.md` 第三节「按老师的一天讲」

### 22　行政文书四件套（R · 22 min）
**讲什么**：格式给底座，事实由口述｜**成品**：通知 / 计划 / 总结 / 简报
**主提示词 `T-22-1`**（P4，合并 `A-24` + `A-25`）：
```
严格按我给的格式，不要自创；只用我口述的事实，缺的标【待补】；

```
**配套**：`A-24` 行政通知、`A-25` 学期总结

### 23　课题与论文（R · 24 min）
**讲什么**：选题缩小两三版，比提纲更重要｜**成品**：缩小后的选题 + 提纲
**主提示词 `T-23-1`**（P4，节选自 `A-30`）：
```
判断这个题目太大还是合适，太大在哪；从我描述的实际情况出发缩小 2–3 个版本，
每个说明研究对象、核心问题、要收集什么数据、大概多长时间、可行吗。
```
**配套**：`A-30` 课题选题缩小、`A-31` 文献综述（只求方向）、`A-32` 课题数据收集方案
**红线**：`A-31` 里那句 **不要生成具体文献的标题、作者、期刊名**，必须原样念一遍

### 24　校本档案与成长记录（R · 20 min）
**讲什么**：让它只提问，不要替我总结｜**成品**：成长记录 + 5 问

**配套**：`A-26` 教学反思、`A-27` 区分自我解释与真正反思、`A-34` 提示词库规范
