# WorkBuddy 教师实战蓝皮书 · 系列课（第一季）

> **v2 成人学习版**｜2026-11-12
> 全书总纲不变：**工具负责「量」，教师负责「读懂学生」；AI 给你答案，WorkBuddy 给你成品。**
> 本版修订依据：① 涉及演示与实操的讲次时长放宽；② 每讲内容做减法；③ 按成人学习理论重排结构；④ 起点按一线教师真实基础设定。

**素材基线**：蓝皮书四篇 26 章 + 8 个编号专题（09–16）+ 附录 A–E + 红线清单，144 张配图。不引用任何私有文档链接。

## 一、这一版改了什么

| | v1 | **v2（本版）** |
|---|---|---|
| 时长 | 统一 12–15 分钟 | 按讲次类型分层：**S 10–14 / R 20–28 / L 32–40** 分钟 |
| 时间用在哪 | 讲解为主 | 放宽的部分**全部给演示与学员跟做**，讲解净时长反而略降 |
| 每讲信息量 | 4–5 条踩坑 + 多个交付物 | **1 个成品 / 1 句原理 / ≤3 条踩坑 / 1 条指令 / 1 条红线** |
| 结构 | 五段录制模板 | **Kolb 四段 + 暂停点 + 提取练习** |
| 起点假设 | 隐含「跟得上」 | 明确：会聊天式 AI、会 Word、会存文件；**不会命令行 / 装环境 / 看报错 / API Key** |

**一句话**：全季讲解净时长 **≈6 小时**（与 v1 持平），含跟做总学时 **≈11 小时**。多出来的 5 小时不是多讲内容，是留给老师自己动手、卡住、重来一遍的时间。

## 二、三类讲次（时长分层的依据）

| 类型 | 适用 | 讲数 | 讲解净时长上限 | 跟做时间 | 单讲总学时 | 暂停点 |
|---|---|---|---|---|---|---|
| **S 概念 / 收尾** | 只建立一个判断，无需动手 | 3（00、01、25） | 8–12 min | 0 | 10–14 min | 0 |
| **R 单成品跟做** | 一个成品、一次操作闭环 | 15 | 12–13 min | 10–14 min | 20–26 min | 1 个 |
| **L 双段实操** | 演示链长、易卡住、要分两步验 | 8（04、13–18、21） | 16–18 min（分 2 段，每段 ≤9） | 16–22 min | 32–40 min | 2 个 |

**L 类为什么必须分两段**：希沃连接、微课渲染、3D 出件这些环节，老师卡住时不能让他从头再看一遍。每段结束设一个暂停点，做完第一段才进第二段。

## 三、教学法依据（每条都落到课程里的具体动作）

| 理论 | 课程里对应什么 |
|---|---|
| **Knowles 成人学习六原则**：需要知道为什么学 | 每讲 P1 写「这讲解决你哪个麻烦」，P2 先放成片；不先讲工具、先讲麻烦 |
| **经验是资源** | P3 固定一问「你现在是怎么做的」，先调出老师已有做法，再给新方法；不否定原做法 |
| **自我概念 / 自主** | 两条观看路径 + 每讲「用 / 别用」由学员自己判断；设「只看不做」的观摩路径，不打卡不排名 |
| **准备度 / 问题中心** | 全部按「一周备课闭环」组织，不按章节顺序；成品就是老师下周要交的东西 |
| **内在动机：马上能用** | 每讲当天交一个能带进课堂的成品，不设「学完以后就会了」的远期承诺 |
| **Kolb 体验学习圈** | 每讲固定四段：具体经验（看成片+回想）→ 反思观察（用/别用）→ 抽象概念（一句原理）→ 主动实验（暂停跟做） |
| **认知负荷理论** | 一讲 1 个新概念、≤2 个新术语（先中文后英文）；指令可复制不靠记忆；一镜到底不跳剪；屏幕字 ≥24pt |
| **Miller「知道 ≠ 会做」** | 只看视频不算完成；P6 强制暂停点，验收看「学员自己做出来的文件」，不看他有没有看完 |
| **提取练习 / 间隔重复** | 每 4 讲的 P8 加一句「回想上一讲的成品放在哪」；30 天计划按周分布，不集中刷完 |
| **70-20-10** | 10% 讲解、20% 同伴互看（每模块末讲 P7 加「找同组老师互看 2 分钟」）、70% 跟做 |

> 不新增讲次：复盘、同伴互看、术语表都嵌在既有页里，或放讲义，避免「内容不要太多」被结构性稀释。

## 四、一线教师的起点假设与照顾措施

**默认会**：用聊天式 AI 问问题、用 Word 写教案、会存文件、会点鼠标。
**默认不会**：命令行、装环境/依赖、看报错日志、配 API Key、建项目目录、判断版本差异。

对应措施：

1. **零配置优先**：04 通用文件助手全程图形界面；13 希沃连接是唯一涉及本地服务的一讲，给「三步回退」而不让老师看日志。
2. **高门槛内容只演示不跟做**：3D 的 Blender 路线 C、微课视频的 ffmpeg 参数、360VR 的着色器原理，教师演示一遍即可，学员不要求动手。
3. **每讲 P6 固定「卡住怎么办」三步**：① 看这三条现象／证据　② 点这里重来一次　③ 实在不行走保底方案（普通 PPT / 真人录音 / 现成模板），**允许跳过，不卡进度**。
4. **练习一律用示例材料**：示例教案、虚构学生数据，不动真实学生数据。
5. **不评分、不打卡、不排名**：错题成因、发给家长的话等判断位仍留给人；同伴互看只看「能不能用」，不评好坏。
6. **术语先中文后英文**：如「技能（Skill）」「工作区」「成品文件」，首次出现给一句大白话，不堆英文缩写。

## 五、每讲内容配额（硬上限）

| 项 | 上限 |
|---|---|
| 成品 | **1 个**（不许「教学设计 + 任务单」两个并交） |
| 原理 | **1 句，≤25 字** |
| 踩坑 | **≤3 条**，且必须来自实测 |
| 可复制指令 | **1 条**，能原样粘进对话框跑通 |
| 红线 | **1 条**，来自附录 C |
| 新术语 | **≤2 个** |
| 演示截屏位 | **≤3 张** |

**每讲必须写「本讲不讲」**，把相邻内容明确挡在门外（见第八节逐讲表最后一列）。这是内容减法最有效的一处：不靠「少写点」，靠明确排除。

## 六、每讲内部结构（替代 v1 五段模板）

| 段 | 对应理论 | 时长 | 做什么 | 课件页 |
|---|---|---|---|---|
| 1 具体经验 | Kolb CE / 经验是资源 | 1 min | 30 秒成片 + 「你现在是怎么做的」 | P2、P3 |
| 2 反思观察 | Kolb RO / 知道为什么 | 2 min | 这讲解决哪个麻烦 + 用/别用 | P3 |
| 3 抽象概念 | Kolb AC / 认知负荷 | 2–3 min | 一句原理 + 操作路径 + 1 条指令 | P4 |
| 4 主动实验 | Kolb AE / Miller | 8–18 min 演示 + 10–22 min 跟做 | 教师演示 → **暂停点** → 学员做 → 验收 | P5、P6、P7 |
| 5 巩固 | 提取练习 | 1 min | 1 条红线 + 「下周在哪用」 | P8 |

**暂停点怎么写**：画面出大字「现在暂停，自己动手」，给 3 步 + 卡住三步回退 + 一个「做完的标志」（例如「文件夹里出现 `.enbx`，双击能打开」）。**没有暂停点的讲次不算实操讲。**

## 十、间隔与提取练习（不新增讲次）

- 每 4 讲（04 / 08 / 12 / 18 / 24 之后）在下一讲 P8 加一句「回想上一讲的成品放在哪个文件夹」，30 秒，不占新页。
- 每模块末讲 P7 加「找同组老师互看 2 分钟」（20% 同伴环节），只看能不能用，不评好坏。
- 30 天计划按周分布：第 1 周复做 01–04，第 2 周挑本学科 2 讲，第 3 周做一个专题，第 4 周把成品带进一次真实课堂。

## 十一、录制顺序与不录清单

**样片先录 01（S）、05（R）、13（L）**——三种类型各一条，测三件事：讲解有没有超时、暂停点字幕够不够大、卡住回退说没说清。**00 最后录**。

**录制硬规则**：讲解段超过上限就剪掉，不许挤占跟做时间；翻车别剪，但翻车片段放 P7 的 ≤3 条踩坑里，不单独成段。

**明确不录**：第 1 章「本书怎么用」；🆕 更新日志、飞书私有链接、待办清单、待补截图清单；附录 A/B/D/E 全文（拆成讲义、指令卡、术语表）；简版教程与公众号传播版。

**第二季**：系统轨第 23–26 章、专题 16「教师用 WorkBuddy 开发工具」（依赖第 6/23/24/26 章）、专题 10 完整版、360VR 零依赖手工作坊、视频素材下载两份（先过版权合规）、`数字人微课教程/` 三份另开小系列。

**讲「怎么做」，不讲「点哪个按钮」**：书里标 ⚠️ 的截图已知会过时（官方平均不到三天一版），录屏比截图稳。
